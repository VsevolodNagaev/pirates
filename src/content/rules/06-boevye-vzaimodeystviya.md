# 6. Боевые взаимодействия



## 6.1. Допуск оружия

Имитации второй половины XVI — рубежа XVI/XVII вв. (текстолит, реактопласт, ЛАРП). Чип допуска непобираем.

**Клинковое одноручное:** шпага, палаш, сабля/карабела, тесак, дага, кинжал.  
Вес ≤ 1400 г, длина ≤ 1120 мм, остриё скругление ≥ 15 мм. Удары — **рубящие**.  
Двуручники и полуторники — **нет**.

**Древковое (ЛАРП):** топоры (древко с боевой частью ≤ 80 см).  
Алебарды / копья — только варзона / штурм форта, по допуску МГ.

**Штыки и багинеты** — не используются.

## 6.2. Огнестрел и артиллерия

Допускаются **специальные лицензированные ЛАРП-изделия**: макеты с внешним сходством с **фитильными, колесцовыми и кремниевыми** пистолями, мушкетами и пушками, не способные поразить человека или нанести ущерб (сжатый воздух / разрешённые пиротехнические изделия — по регламенту допуска МГ).

Калибр снарядов для ручного стрелкового — по safety-листу МГ (ориентир «Корсаров»: 20–25 мм, войлок/ППУ). Запрещённые мощности зарядов — как в исходном safety-списке серии (усиленные Хилти и аналоги).

Многозарядность — только персональный допуск МГ.

**Пушки:** макеты орудий эпохи, ствол ≥ 40 см; на суше — лафет. Снаряд — проколотый теннисный мяч. Защита глаз и кистей рекомендуется. Ручные бомбарды — запрещены.

## 6.3. Доспех

По периоду и географии:

- **На кораблях** тяжёлых всадников нет: максимум лёгкая защита по согласованию (если вообще).
- **В портах и фортах** возможны элементы доспеха городского гарнизона и тяжёлой конницы / пехоты на берегу: нагрудник, морион, шишак и т.п. — по статусу и допуску МГ.

Эффекты (если доспех допущен):
- корпус блокирует клинок/древко по зоне доспеха;
- иммунитет к кулуарному убийству;
- шлем — иммунитет к оглушению.

**Щиты (включая баклеры) — не допускаются.**

## 6.4. Хиты и ранения

База: **2 хита**. Максимум для игрока: **3** (через роль/сюжет МГ).

Непоражаемые: пах, запястья, кисти, голова, шея, ступни, суставы.  
Поражаемые: «рубашка и штаны».

Клинковое / древковое: −1 хит, доспех не пробивают.  
Пистоль / мушкет: −2 хита, доспех пробивают.

Добивание — по тяжёлому/критическому.  
Смерть: неподвижно **15 мин днём / 5 мин ночью**, затем мертвяк.

Дневная боёвка: 9:00–21:00.  
Ночь: только одноручный ЛАРП (+ колдстил до 40 см по допуску).

## 6.5. Кулуарка, оглушение, плен, обыск

- **Кулуарка:** сзади ножом по груди + «ты убит» (не работает по корпусному доспеху).
- **Оглушение:** касание небоевой частью + «оглушен»; 3 минуты; шлем защищает.
- **Плен:** верёвка/кандалы без травмы; кормление раз в час; комфорт при долгом плене; уведомление МГ.
- **Пытки:** только игровой отыгрыш в согласованных границах, без реального вреда.
- **Обыск:** указанием зоны одежды/антуража.
