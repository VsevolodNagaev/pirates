# 5. Форты и берег



## 5.1. Штурм форта

Ядро по форту = **−1 хит**. После нуля хитов — высадка / захват.

При обороне можно стрелять из корабельных пушек и лафетных пушек на земле. С рук «ручными бомбардами» — запрещено.

Гарнизон и люди на корабле при попадании из мушкета на **5 минут** теряют возможность двигаться и участвовать в бою (как в исходных механиках «Корсаров»).

## 5.2. Захват врасплох

Гарнизон может остановить высадку:
1. голосом **«Стоп»**, пока первый десантник не сошёл на берег;
2. предупредительным залпом из пушки.

Атакующие могут объявить штурм первым выстрелом. Если гарнизон не остановил высадку — форт может быть взят без обстрела с воды.

При 0 хитов форт поднимает белый флаг.

## 5.3. Ленты гарнизона

Форт имеет N лент гарнизона (число по уровню форта / экономике локации).  
Лента = виртуальный боец: при потере хитов умирает лента, не персонаж; игрок берёт новую у штандарта. Без лент — играешь своим персонажем.

## 5.4. Корабли в порту

Пришвартованные, но не в обороне: до **−50%** хитов; окончательно «насовсем» не топить без отдельных указаний МГ. После боя — ремонт.
